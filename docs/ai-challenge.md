# AI挑战赛：界面选择与业务约定

2026-11-02，用户选定第5版“紧凑工作台”，并要求移除举办人、时间标准和报名方式的展示。原型已更新并默认打开第5版。正式模块已在`ysy`分支实现、完成云端部署，并核验实际高创页面；未创建虚假赛事、参赛组或成绩。

## 已确认业务

- 高创举办赛事，上传赛事介绍文件、设置名称、开始时间与截止时间；沿用此前确认的首页预览要求，由举办人提供赛事标题与封面。
- 发布后成员可查看报名入口，报名包含组名、组长、组内成员。报名成功后，高创和陈老师可查看参赛组信息。
- 截止前提交最终作品，重新上传覆盖旧版本；高创和陈老师可查看所有组作品，组内成员只可查看本组作品。
- 截止后由高创上传CSV评分表和报名组位次，评分与位次向团队成员开放。公开成绩不公开各组私密作品。
- 所有赛事时间使用北京时间。权限必须在服务端验证，超级管理员等通用角色不能自动获得私密作品查看权。
- 用户确认陈老师对应“陈老师账号”，但当前尚未加入团队；不得按姓名匹配、虚构账号或将其他成员当作陈老师。正式接入时需绑定其真实已加入账号。

原型暂按组长本人发起报名、发布后至截止前可以报名、组内成员均可更新共同作品展示。这些实现细节在正式开发时结合用户后续说明处理。

## 正式实现

小程序入口为`miniprogram/components/ai-challenge`，采用紧凑指标卡与报名/作品/成绩入口，保留实际开始与截止时间。用户要求删除的三处展示不会出现在正式页面。

服务端位于`cloudfunctions/weeklySharing/challenge-*.js`，通过既有`weeklySharing`函数的`challenge.*`操作提供服务。原生部署未保留新增子目录，因此挑战赛文件使用独立名称放在云函数根目录，避免丢失相对路径或与原模块同名。新增`challengeEvents`、`challengeTeams`、`challengeFiles`、`challengeClaims`、`challengeSettings`、`challengeAudit`六个集合，初始化必须验证ADMINONLY权限并创建赛事与参赛组索引；存储沿用已核实的PRIVATE预设。所有文件按冻结副本和逐块鉴权读取，不向客户端提供云文件ID或临时下载地址。

仅固定高创账号且具备现有分享审批角色的活跃成员可发布赛事、绑定陈老师和发布成绩。陈老师账号当前尚未加入，不做自动绑定；加入后，高创可在“陈老师查看权限”中选择账号，并确认姓名和完整账号编号。该绑定记录审计。超级管理员与领导角色没有额外作品读取权限。

组长本人发起报名，选择真实活跃成员。每名成员每场只能加入一组；组名经NFKC规范化后保持唯一，使用事务内的成员与组名占位防止并发重复报名。只有组长可在截止前修改报名，组内任意成员可更新共同作品。已有报名后锁定赛事开始和截止时间；已截止的赛事不能重新开放。

作品提交使用组版本避免并发静默覆盖，并以请求ID支持重试。新版本提交成功后旧副本被替换并失去读取资格，随后清理旧存储文件；未提交成功的文件不会覆盖本组当前作品。变更组内成员或撤销成员身份会停止读取，下载每块前后均复查当前身份、绑定和最新作品。赛事介绍和已公布评分表对活跃成员可读，作品不会随成绩公开。

评分CSV在赛事截止后由高创上传、预览并确认公布，需包含“组名、总分（或得分/评分）、位次”，可添加明细评分列，覆盖全部报名组。支持UTF-8/BOM及GB18030，最多256KB/1000条成绩；解析带引号与换行，校验组名、数字、重复组及公式单元格。公布前仅高创预览，公布后团队可查看排序结果与完整CSV。

报名、作品更新和成绩公布接入现有消息中心，消息正文不包含私密组内资料，跳转仍由服务端校验权限。首页轮播接入真正处于开始与截止时间之间的已发布赛事，显示高创设置的标题、封面并直达赛事；没有进行中赛事时显示空态。

## 2026-11-03：修复上传时编辑页被同步重置

微信文件选择器触发应用离开/返回后，实时同步重新连接并首次发布全部频道，其中包含`members`。原挑战赛组件将任何成员通知都当作当前身份变化，直接清空表单并重新加载列表，导致上传回调读取空表单而失败。进入编辑之前已发出的后台列表响应也可能稍后覆盖编辑页面。

修复以成员服务已有的账号、状态、修订号与角色快照判断当前身份是否确实变化；普通成员重连通知不清空编辑表单，实际权限变化仍立即清空草稿。编辑/上传期间的普通同步和下拉刷新保留名称、时间及已上传附件；进入编辑或权限选择时作废之前的查询并暂停详情时间刷新。上传前固定赛事编号，选择器返回及上传完成后核验原身份与原表单，避免权限变更后的迟到结果写回。发布响应也作相同身份检查。全部权限仍由原云端接口校验。

78项测试通过，其中新增5项上传及刷新回归。模拟器使用受控文件选择、上传回调并触发真实应用离开/返回，实际观察到一次重连`members`通知；介绍文件上传后仍为编辑状态，继续上传封面并触发同步、手动刷新后，赛事名称、两个附件和原赛事编号均保留，错误提示为空。验证后恢复原服务方法并退出临时表单，没有向云端写入测试赛事或文件。本次只修改前端，已重新编译，无云函数部署确认。
