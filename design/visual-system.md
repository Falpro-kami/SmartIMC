# 智慧IMC 视觉规范

2026-10-27 用户正式确认，适用于现有全部页面，以及后续所有功能开发。

## 参考与方向

采用「四列宫格＋分区轻卡」，融合 C 版的高对比文字和排版，与 E 版的轻卡边界。
内部确认稿：`approved-four-column-light-cards.png`。参考图含内部资料，不随公开仓库发布；公开仓库保留以下尺寸、字体和配色规范，协作者需要参考图时另行获取脱敏版本。
确认稿是字号、字重、图标比例、卡片尺寸和留白关系的验收基准。不得只保留颜色与四列结构后自行缩小、紧凑化。真实微信状态栏和胶囊按平台安全区处理，不能遮挡标题或操作。

## 颜色与形态

调色板参考位于 `miniprogram/styles/theme.wxss`，该文件不再导入运行时样式。运行时 WXSS 直接写入确认的颜色、边框和尺寸；窄屏间距通过各样式的媒体规则明确设置，避免跨组件主题变量作用域影响关键视觉效果。页面根节点保留 `imc-theme` 作为语义标记。

| 用途 | 变量 | 值 |
| --- | --- | --- |
| 正文、标题、图标 | --imc-text | #101b2b |
| 字段标签、辅助正文 | --imc-secondary | #526173 |
| 时间、占位及次要状态 | --imc-muted | #637083 |
| 卡片、分隔线 | --imc-line | #dde3ec |
| 搜索框、表头及占位背景 | --imc-surface | #f5f6f8 |
| 操作、当前导航 | --imc-accent | #005bac |
| 浅色选中背景 | --imc-accent-soft | #edf3f8 |
| 正在使用、成功 | --imc-success | #087f58 |
| 错误 | --imc-danger | #ad4037 |
| 轻卡圆角 | --imc-radius | 10px |
| 页面边距 | --imc-gutter | 16px，窄屏 12px |

主体始终白色。轻卡使用 1px 实线边框、不加投影，不叠加多层卡片。弹窗顶部圆角 16px，遮罩石墨色 30% 透明度。
禁止渐变、毛玻璃、彩色大底块、装饰性横幅和无业务依据的统计。

## 字体与间距

- 系统无衬线字体：Apple / PingFang SC / Microsoft YaHei / Segoe UI / sans-serif。中文不使用衬线体，不强制下载字体。
- 居中页面标题 20px / 600，页头姓名 21px / 600，分区标题 20px / 600，正文与表单 16px / 400，辅助正文 13–14px。
- 表格正文 15px；320px 窄屏可缩至 13px，表头与状态最低 12px。页头角色标签12px，不能依赖颜色表达角色。
- 宫格名称 15px 单行，窄屏 13px；姓名允许省略，角色标签可换行，长业务字段应折行而不是撑宽页面。
- 行高通常 1.5–1.6；数字用 tabular-nums，设备编号保留前导零。
- 间距以 4px / 8px 网格组织，卡片间 12–16px，常规卡片内边距 16px，正文行高及高度按内容增长。
- 触控区域至少 44px；底部导航与按钮预留 safe-area-inset-bottom。

## 组件与页面

- 工作台：常用应用上、全部应用下，各一个分区轻卡。四列宫格，图标在上、名称在下。常用排序仍由当前用户使用数据决定。图标框 56px（窄屏 52px），图形光学大小约 40–44px。单项约 100px 高，分区标题 20px，分区卡片间距 14px。
- 图标：统一石墨色线性语言和线宽；资源由 `scripts/generate-workbench-icons.ps1` 生成。底部导航继续 WXSS 绘制，避免图片加载依赖；选中蓝色、非选中深灰。
- 页头：首页、工作台、我的都有居中标题；共用头像、姓名、IMC、角色矩形标签与消息铃铛。共用页头整体吸顶，状态栏安全区、标题、身份与消息入口在滚动时保持可见，只有下方业务内容滚动。使用白色不透明背景与自然占位，高度随角色换行和错误状态增长，不设置会截断内容的固定高度。标题位于状态栏下方的独立导航行并避开微信胶囊，身份区放在导航行下方，通知仍位于身份区右侧。消息入口采用上图标、下方单行「消息」文字，字号 13px，与左侧身份区垂直居中；未读数量角标固定于铃铛右上角，红底、11px白字、2px白边，1至99条显示数字，100条起显示「99+」，零条隐藏。头像 60px（窄屏 52px），多个角色可换行；头像打开左侧团队栏。
- 周报删除：仅管理员显示，列表卡片右上角44px「更多」打开原生菜单，含周期设置和删除；已修订旧版只含删除。详情管理区保留红色删除按钮，使用原生确认弹窗。管理按钮不嵌套在详情入口中，普通成员不显示该操作。
- 我的：个人资料、我的事务、团队成员、成员与权限、数据与服务、设置与帮助分别采用轻卡；不再显示重复的「IMC 成员身份」卡片、加入状态或当前角色，身份沿用头像旁的标签。我的事务保留我的设备、我的提交、我的收藏，权限入口按当前真实权限显示。数据与服务仅超级管理员可见，内含数据备份和到期提醒；到期提醒行右侧展示真实剩余天数，14天内用错误色突出。备份及到期详情沿用轻卡、16px字段和44px以上按钮，密码输入框48px，创建与下载/导出为明确的手动操作。设置与帮助二级页沿用轻卡列表。申请与审批统一放在工作台，不在「我的」增加独立申请入口；未接入的业务只显示明确的筹备状态，不伪造记录或实现说明。
- 入组拦截：首次进入在身份验证完成前不渲染业务区，也不执行原业务加载；本次运行验证通过后，切页直接复用内存身份，不重复验证或闪现拦截页；未加入者显示不可跳过的入组申请表，姓名必填、头像主动选择，提交后只显示等待审核状态；待审核、停用、移出及验证失败均隐藏底部导航并拦截直接进入二级页面。拦截界面沿用白底轻卡，不提供关闭或跳过按钮，只有服务器确认已审核且启用的 IMC 成员才放行。
- 列表：成员、消息、审批用轻卡行；姓名/标题主层级，真实业务类型和时间为辅助层级。
- 消息页：列表上方右对齐蓝色「全部已读」文字按钮，触控高度至少44px，处理中禁用并显示加载状态，没有未读时禁用。仅用户主动点击才批量标记本人消息，保留原有单条标记入口。
- 周报预览例外（2026-10-28）：模板预览及成员填写后的效果预览使用连续文档排版，去掉周报名称、姓名卡片和分区轻卡边框；顶部仅居中显示提交成员姓名，20px/600，长姓名自然换行。保留原标题层级、正文、图片和附件；模板结构仍可展开说明。本人「效果预览」另起原生页面，返回原填写页面，预览本身不提交。该例外只适用于预览，其他页面沿用分区轻卡。
- 申请与审批：页内固定三个等宽选项「我的申请」「待我审批」「我已审批」，默认我的申请；选中项蓝色文字与浅蓝底，四字单行、触控高度至少44px。记录使用分区轻卡，待我审批仅呈现本人有权处理的事项，我已审批仅包含本人实际处理的申请，不将普通角色调整算作审批；处理申请不改变消息已读状态。
- 设备：保留卡片和表格浏览方式。搜索与筛选间的浏览方式按钮保持单行文字。表格不添加设备总量和状态选项卡。设备卡保留图片框，详情与筛选弹窗沿用同一字体、边界、状态色。
- 表单：白色轻卡包裹相关字段，字段标签深灰、输入内容石墨色；主按钮蓝色，次按钮浅灰或浅蓝。
- 周报：用户于2026-10-28恢复自定义表单模板，字段类型为文本、数字、日期、单选、多选、附件；单行/多行统一为富文本框，使用微信原生 editor，支持基础格式和 JPG/PNG 图片插入。编辑器按用户提供的飞书参考采用白底、细分隔线、6px小圆角和纯图标工具栏：Aa下拉正文/H1/H2/H3，无序/有序列表、粗体、中划线、下划线、斜体、文字颜色和高亮色，右端固定更多图标。窄屏单行横向滚动，不能换成多排文字按钮；图标20px、触控区域44px。颜色面板为六列色板并标记当前颜色；更多浮层含图片、任务列表、缩进和四种对齐，底部保留撤销、重做、清除格式图标。菜单白底、细边框和轻微浮层阴影，展开不推挤正文；长按显示操作名称并提供无障碍标签。按用户最新要求不提供超链接、引用块或OKR入口。保留文字选区，横向滑动不触发格式操作。编辑区16px正文、至少200px高；只读正文隐藏工具栏。所有字段统一整行排列，不提供并排设置。标题支持最多6级，分组仅组织层级，只有最深层非必填项有复选框，勾选后显示输入区；必填项直接填写。叶子勾选自动激活全部祖先，状态与草稿一同保存。阅读版保留全部一级标题，只显示已勾选且填写的分支及其祖先，未勾选或空白的同级分支隐藏；一级标题下完全无内容时只显示该标题及一处「无」。无子标题的一级分区直接填写文本，留空为「无」。数字0及图片不能当作空白。一级标题20px/600并编号「1.」，二级18px/600并编号「（1）」，更深层16px/600、完整层级编号及逐级缩进，正文16px。每项可选填说明文字，填写时紧跟标题右侧显示44px以上触控区域的「说明」按钮，不推到整行最右侧，点击展开/收起14px纯文本说明，保留换行、长文本折行；无说明不显示入口，正式阅读版隐藏说明。模板编辑页右上角「预览」打开独立页面，提供「模板结构」「阅读效果」，前者展示所有标题及说明入口，后者按正式阅读规则展示；共用正式阅读组件，返回保留编辑状态。管理员可编辑模板及规则，公共模板修改不自动改动周期快照。周期设置允许更新已发布设置，独立页面「编辑本期表单」在应用后回设置页、更新周期才生效。无填写记录可直接修正表单；已有填写/上传时，原生确认框说明旧版只读、原内容保留、新版重新填写提交，再发布关联修订版。列表及详情以辅助字号显示版次，旧版显示「已修订」，详情提供「查看上一版」「查看新版」按钮。正文与附件自动保存草稿，无保存草稿按钮；提交不经审批，修改不覆盖已提交版本。Word/PDF保留独立文件选择器，图片仅通过正文插入。定时发布、截止时间、催交和统计保持原业务。复用已注册模块页，不新增原生路由。
- 周报浏览返回：周报列表、周期详情、团队提交、成员周报、发布周报、周期设置、表单模板列表及模板新建/编辑，均通过已注册模块页的参数分别入原生页面栈；左上角返回及系统返回逐层退回，不能把页内模式切换当作子页面导航。模板选择页返回原发布页面，并保留标题、日期、名单和滚动位置；模板编辑保存后退回模板列表。发布成功后以周期详情替换发布页，返回仍到原周报列表；周期设置保存后回原周期详情。查看成员后返回同一团队列表，保留筛选、滚动位置和已加载记录；「周报列表」按钮只匹配已有周报列表，不能误匹配无周期ID的模板或发布页。通知直达没有列表祖先时重建列表入口，不堆叠重复团队页。

## 周报清晰轻卡（2026-10-28 确认）

用户从四版界面中选定第一版「清晰轻卡」，作为周报模块后续视觉基准，阅读预览的无卡片例外继续生效。

- 列表标题24px/600。模板、发布单独一行，仅管理员显示；卡片18px内边距、16px间距、10px圆角、1px细边框。正常日期周期用「10月26日—11月1日」作标题，自定义标题完整保留；跨年或非本年显示年份，避免不同年份混淆。
- 按北京时间日期将开放且覆盖当天、未被修订的周期放在本期；管理员的定时/取消计划另列「发布计划」，已发布但尚未开始的开放周期列「即将开始」，其余记录列「历史周报」。分页与原顺序保留，分组只影响展示，不改截止规则或业务状态。
- 普通成员及其他业务管理员：显示本人提交状态，按实际可填写状态显示填写、继续填写、修改或查看入口。无管理入口、无空白管理行。预览和提交并排等宽；只读时只剩预览并占满宽度。免交或未纳入应交名单且没有原记录时不展示空填写区，已有提交和历史仍按原权限保留。
- 领导：隐藏本人草稿/提交状态及填写控件，主入口为居中的「查看团队提交」，单按钮占满可用宽度。团队页仅保留统计、筛选、成员阅读入口，不留催交/导出的空操作区。
- 周报管理员、超级管理员：成员填写入口和团队入口并排，模板/发布在页头独立成行，单周期管理收入「更多」。未纳入应交名单时以查看团队提交为主；定时/取消周期以周期设置为主。
- 领导叠加管理员：沿用领导阅读布局，同时提供模板/发布及周期管理；详情中团队入口单独一行，周期设置和删除单独一行，不能将三个按钮硬挤在一起。查看他人成员周报时不显示周期删除和本人提交控件，返回仍走原生层级。
- 团队提交：每位成员一个轻卡，姓名和状态在首行，时间在下方；表单周报在原成员卡片中展开，文件直接查看/下载。催交和导出按各自权限独立显示，单项占满该行，双项等宽并排；已关闭周期不显示催交。
- 发布、周期设置、模板编辑继续使用相同边框、圆角和间距；长模板名必须换行，不能挤出容器；预览继续纯文档、姓名居中，不增加周报标题或分区边框。

## 验收

检查 320px、390px、430px 布局；长姓名、多角色、设备长名、缺失值、空态、错误、弹窗与底部安全区。
视觉验证不得替代权限、消息手动标记已读、资料保存及原生分享的业务验证。
验收先比较实际代码渲染与确认稿的字号、图标、卡片宽高及留白；功能测试通过、没有溢出不代表视觉一致。检查轻卡实际边框宽度为 1px、实线、颜色 #dde3ec、圆角至少 8px；分别检查首页、工作台、我的选中后文字和图形填充都为 #005bac。额外模拟主题变量不可用，确认关键效果仍显示。必须明确区分 HTML 布局预览和微信模拟器、真机结果。
修改源码后需重新编译；已上传的体验版需再次上传才能包含新的界面。
