# 界面约定

用户已正式确定所有页面和后续开发统一使用「四列宫格＋分区轻卡」。
修改界面前阅读 [项目设计规范](../design/visual-system.md)。内部确认稿位于 `../design/approved-four-column-light-cards.png`，含内部资料，不随公开仓库发布；需要参考图时另行获取脱敏版本。

- 白色主体、C 版深色文字与排版、E 版细边框与小圆角；以 `styles/theme.wxss` 为调色板参考，运行时样式使用明确值，避免主题变量作用域导致边框、选中态失效；页面根节点保留 `imc-theme` 标记。
- 工作台四列宫格；常用应用与全部应用分别用分区轻卡，不改双列，不给每个应用另加卡片。
- 字体统一系统无衬线，正文 16px、页面和分区标题 20px、页头姓名 21px、辅助信息 13–14px；页头按用户要求轻微收紧，头像60px、身份标签12px、消息文字13px，触控区域仍至少44px。表格和窄屏以完整、清晰显示为准。
- 深色石墨图标，蓝色交互状态，绿色正在使用；同类状态跨页一致。
- 重要按钮点击区域至少 44px，适配窄屏和底部安全区，角色标签允许换行。
- 未经用户要求，不自行增加说明性小字、使用教学文案或实现细节说明。
- 字段标签、实际业务数据、必要的加载状态和错误反馈可以正常展示。
- 「实验室设备」「浏览方式」保持单行；设备缺失值使用 `-`，编号保留前导零。
- 严格按确认稿还原视觉比例，不以“缩小图标、缩小名称、压缩留白”代替还原；功能测试和无溢出检查不能代替视觉对照。宫格图标框 56px、名称 15px，仅窄屏使用较小尺寸。首页、工作台、我的需要居中标题。
